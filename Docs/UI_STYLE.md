## 글꼴

- 기본: 단조 `Assets/Font/Danjo-bold-Regular SDF`(정적 4096 아틀라스). 단조 원본 OTF의 `·`·`•`는 빈 글리프라, 빠진 글자는 폴백 `LiberationSans SDF`(TMP 기본, Resources)가 채운다. 공식 스테이지 이름의 `·`가 여기서 나온다.
- 영어·기호 전용: Kenney Mini `Assets/Font/Kenney Mini UI SDF`. 키 설정 목록의 **입력값**(Space, Left Stick 같은 키 이름)만 쓴다.
- 문구는 한국어다. 키 설정 행 이름(이동 위, 들기/던지기, 리스폰 …)도 한국어 단조다. 키 이름만 Input System 표기(영어)를 그대로 둔다.
- 버튼 라벨의 항목 나열은 `/`(예: `스프링/바운스 시험`), 데이터의 표시 이름은 `·`를 써도 된다.

## 크기와 여백

- 버튼 높이: 64(격자·도구: 준비 맵 버튼 290×64, 맵 에디터 도구 196×64·상단 막대), 72(기본·뒤로: 300×72, 키 설정 닫기 220×72), 96(Main 메뉴 480×96). 설정 루트처럼 화면을 채우는 목록은 레이아웃이 높이를 정한다(175~184).
- 버튼 라벨 안쪽 여백: 가로 24·세로 14(`PixelButton.frameInset`). 아이콘이 있으면 왼쪽에 아이콘 크기+8을 더 띈다(`iconGap`).
- 격자 간격 12(준비 맵 버튼), 세로 목록 간격 12(맵 에디터 도구 64+12=76).
- 입력란 `PixelCodeField` 590×88, 글자 영역은 가로 28·세로 8 안쪽.
- 패널 `PixelPanel`: 부모보다 가로 520·세로 120 작게(좌우 260·상하 60 여백), 제목은 위에서 50 내려 높이 80, 좌우 80 안쪽.
- 프레임 스프라이트는 Sliced. 패널 Sprite Border 48px, 버튼·입력 프레임 16px. 도트 단위는 4px.

## 선택·포커스 표시

| 상태 | 표시 | 담당 |
|---|---|---|
| 키보드·패드 포커스 | 버튼 바깥 링(버튼에서 2px 띄운 짙은 청록 12px, 가운데 크림 6px) + 왼쪽 도트 화살표(30×54, 6px 단위, 청록 윤곽·크림 면, 끝이 테두리에 6px 걸침) | `SelectionFocusIndicator` + `PixelFocusIndicator` 프리팹 |
| 고른 항목(현재 도구·확정 맵) | 버튼 안쪽 프레임을 연두 주 프레임으로 교체, 라벨 짙은 청록 | `PixelButton.SetHighlighted` |
| 마우스 호버 | ColorTint 밝아짐 | `Button` |

- 포커스 링은 탐색 모드에서만 보인다. 포인터 모드는 `UIInputModeController`가 선택을 비워 링이 사라진다.
- 링과 화살표는 남색 위에서 크림이, 크림 패널 위에서 짙은 청록이 보이도록 두 겹이다. 화살표는 옆 버튼·설정 행의 ◀ 버튼과 일부 겹칠 수 있다(격자 간격 12). 새 Selectable에는 `SelectionFocusIndicator`와 `PixelFocusIndicator` 자식을 붙인다.

## 이미지 생성 지시문 기준

- 4px 도트 격자, 안티앨리어싱 없음, 투명 배경 PNG.
- 위 색표의 남색·크림·짙은 청록·연두(183, 239, 53)·청록 발판색만 쓴다. 강조는 연두, 외곽선은 짙은 청록.
- 9-slice가 필요한 프레임은 가장자리 중앙을 단순하게 두고 모서리 16px(패널은 48px) 안에 장식을 모은다.
- 저장 위치·이름은 `CLAUDE.md` 구조 규칙(`Generated/Codex/`, `codex_` 접두사)을 따른다.
