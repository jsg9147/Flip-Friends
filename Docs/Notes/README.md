# Notes

1회성 기록을 두는 곳이다. 기능 문서(`Docs/*.md`)에 남기면 지침이 길어지고, 지우면 다시 조사해야 하는 내용만 여기에 쓴다.

- 파일명은 `YYYY-MM-DD-주제.md`로 한다. 예: `2026-10-01-steam-lobby-timeout.md`
- 쓸 것: 실패한 시도와 이유, 측정값, 외부 문서 조사 결과, 재현 절차
- 쓰지 않을 것: 현재 구현 상태(기능 문서), 지켜야 할 규칙(`CLAUDE.md`나 `.claude/rules/`), 변경 이력(Git)
- 이 폴더의 파일은 자동으로 읽히지 않는다. 필요한 노트는 기능 문서에서 한 줄로 링크한다.
- 내용이 규칙으로 굳으면 해당 지침 파일로 옮기고 노트는 지운다.
