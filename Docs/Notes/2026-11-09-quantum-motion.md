# 제품11 이동 발판·전환 지형·트랩 검증

- 상태: Historical. 구현 범위와 다음 작업은 [Quantum 전환 문서](../QUANTUM_MIGRATION.md)를 따른다.

## 원본 근거와 차이

- Unity에서 원본 프리팹의 발판 93개와 감지 발판/버튼·이동/회전 설정을 읽었다. Stage11 감지 발판은 x+15, 진행률/초1, 대기0, 이징0.2다. Stage13~19 낙하 발판은 y−5, 진행률/초1, 경유점 대기0.3초, 복귀0.5초, 이징0.2, Player 마스크다. Stage12 레이저 막대와 Stage20 경로 트랩은 승객 없는 트리거다. Stage20 경로 트랩은 4개 경유점, 진행률/초8, 비왕복 반복이다.
- `PlatformMotion`의 원본50Hz float 누적이 결정한 구간 길이·경유점 대기(ceil−1틱)를 60Hz로 올림하고 이징은 FP 표로 변환한다. 이동 트랩은 거리/초로 왕복한다. `Move Trap`은 Box, `Move Trap Round` Variant는 Circle이다. Stage21 이동 트랩은 x−16, 속도7, 회전1000도/초 설정이다. Stage9의 랜덤 회전 예는45±5도/초와 양방향 선택이다. Quantum은 런타임 Unity RNG 대신 프레임 RNG에서 한 번 뽑는다.
- 원본 감지 발판은 플레이어 접지 뒤 출발하며 리셋 직후0.2초 감지 대기, 설정 출발 지연, 완료 후 복귀/감지 재대기, 완료 때 판정 비활성/표시 소멸을 지원한다. 고체 버튼은 아래에서 머리 접촉, 트리거 버튼은 접촉 집합 진입이다. Quantum에서는 버튼을 발판 이동 전에 처리해 같은 틱의 복수 요청을 한 세대로 합친다. 복귀점 점유와 승객·운반물 끼임 때 발판을 대기시켜 관통을 방지한다. 원본처럼 느슨한 상자의 별도 운반은 없다.
- 자동 전환은 Stage20·21 `OnOffManager`의3초 설정을 참고했다. `QuantumStageTerrainToggle`은 동일 이름·간격의 고체 Box 그룹에서 켜짐/꺼짐을 한 번에 바꾼다. 활성화될 공간이 점유되어 있으면 그룹이 기다린다. 수동 OnOffSwitch, 문, 벨트 연결은 별도 범위다.

## 작성과 검증

- `Official Motion Test.prefab`: Ground Tilemap, 2인 시작점, 상자, 도착점, 왕복/감지 발판, 감지 발판 리셋 버튼, 자동 전환 Box 2개, 원형 이동/Box 랜덤 회전/Box 경로 트랩. 움직이는 트랩은 `QuantumStageMotion`과 `QuantumStageTrap`을 같은 오브젝트에 둔다. 발판은 단일 고체 Box, 트랩은 단일 트리거 원/Box/볼록 Polygon이다. 초기 XY 회전0·배율1·비활성/다중 콜라이더·Composite/Effector·동적 Rigidbody를 검사한다. 원본 프리팹은 보존했다.
- 기존 공식 작성 메뉴로 변환하면 `official-motion-test`가 목록에 등록된다. 원본 설정을 다시 변환한 해시·ID 정렬·속도/경유점 해시 민감도와 변환6종/작성기7종 거부를 확인했다.
- `QuantumMotionChecks.Run`: 실제 입력을 기록하고 별도 러너에서 다른 서비스 간격으로 재생, 확정120~2400의20개 체크섬 일치. 확정2400 `14255308147419636815`, 완료858, 플레이어 최대 피격3회. 다중 승객·상자 운반·점프·비관통을 관측했다. 직접23종은 플레이어/상자 운반, 느슨한 상자 비운반, 벽·천장·끼임, 감지/대기/완료/복귀, 동일 틱 중복 리셋, 점유 대기, 전환 지형, 원형/회전 피격을 포함한다.
- `QuantumProductChecks.RunOffline`을 다른 Main 검사보다 먼저 실행했다. 제품 전체 오프라인과 Tilemap·공식 시험 재생10/10개, 경사16개, 피격25개, 스프링/바운스20개 및 각 Main 회귀를 확인했다. 새 맵 Main 선택/전원 완료/복귀/재진입/종료·러너와 입력0을 확인했다.
- 개발 Photon 동일 PC 두 연결: asia RTT111/116ms, 확정240~2400의19개 체크섬과 위치·각도·회전속도·위상·세대가 일치했다. 완료1755, 확정2400 `5456793057512536667`, 러너·연결·입력 정리 True. 다른 PC·실제3~4인·지연/손실 주입·배포 빌드·Steam 출시 인증은 미실행이다.
- 지정 dotnet 런타임·에디터와 Unity 컴파일 오류0. 기존 공식 콘텐츠4종의 작성 검사를 다시 통과했다. 종료 뒤 Main은 미저장 상태이며 작업 전후 사본의 SHA-256이 동일하다. 러너0·입력0·자동 씬 로딩 Disabled를 확인했다. 로그, 원시 입력, Main 완료/종료 문구, 화면 캡처는 로컬 `Logs/QuantumMotion*`에 있다.
