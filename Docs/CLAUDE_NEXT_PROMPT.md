# Claude Code 작업 요청 — Quantum 컨베이어 이식

`C:\Unity Project\Flip-Friends`에서 Quantum 전환의 다음 묶음을 구현해줘. 기준은 제품12 / `ff-product-12`다. 컨베이어의 외부 속도와 OnOff 그룹 연결을 이식하고, 별도 공식 시험 맵을 작성해 변환부터 Main 왕복과 개발 Photon 두 연결까지 검증해줘. 조사나 계획에서 멈추지 말고 구현, 검증, 문서 갱신까지 진행해줘.

## 착수

1. `CLAUDE.md`, `PROJECT_DOCUMENTATION.md`, `Docs/QUANTUM_MIGRATION.md`, `Docs/NEXT_SESSION.md`를 읽어. 실제 수정 영역에 필요한 규칙과 기능 문서만 추가로 읽고, 원본 동작이나 측정 근거가 필요할 때만 Notes를 확인해.
2. Git 상태와 열린 Unity 씬의 미저장 여부를 확인하고 기존 작업을 보존해. 프로젝트 파일에서 Unity 6000.6.8f1과 Quantum 3.0.14 Stable 2241을 확인해.
3. 원본 `Conveyor`, `OnOffManager`, 플레이어 이동 및 발판 코드를 실제 프리팹 설정과 대조해. 특히 Stage 20·21의 고정 벨트와 이동 벨트, 감지 마스크·방향·속도 0·자동/수동 그룹과 초기 상태를 확인해. 원본에 없는 중대한 게임 규칙 결정만 질문해.

## 구현

- 원본의 적용 대상, 접촉·이탈·점프 조건, 외부 속도 방향과 크기를 확인한 뒤 FP·틱·프레임 상태로 옮겨. 이동 발판에 올라탄 경우 발판 변위와 벨트 속도의 적용 순서를 명시하고 이중 적용, 관통, 끼임을 막아. 경사·벽·천장, 역방향 입력, 운반 중 플레이어·상자, 느슨한 상자, 리셋·복귀의 동작을 각각 확인해.
- 제품12 OnOff 그룹의 적용 상태를 재사용해. 같은 틱의 여러 버튼·자동 전환과 점유 대기 때 벨트 방향이 언제 바뀌는지 검증해. 벨트만 연결된 원본 그룹도 고려하고, 사용 가능한 구성과 거부할 구성을 분명히 해.
- Quantum 전용 작성 컴포넌트, 변환·해시·프레임 기반 표시와 별도 공식 시험 맵을 추가해. 최소한 고정·이동 벨트와 OnOff 반전을 맵이나 직접 검사로 재현해. 누락·중복·잘못된 참조·미지원 형상은 위치와 원인을 표시하며 거부해. 새 콘텐츠와 제품 합의 버전을 갱신하고 기존 맵 해시와 MapData 2.1 호환성을 확인해.
- 원본 21개 스테이지를 보존하고 Stage7의 직접 이식은 보류해. 대포·투사체, 최대 4인 확장과 Steam 출시 인증은 후속 범위로 둬.
