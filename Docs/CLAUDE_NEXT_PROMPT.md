# Claude Code 작업 요청 — Quantum 대포/투사체 이식

`C:\Unity Project\Flip-Friends`에서 Quantum 전환의 다음 묶음을 구현해줘. 기준은 제품13 / `ff-product-13`이다. 대포의 발사 주기와 투사체의 이동·충돌·소멸·피격 연결을 이식하고, 별도 공식 시험 맵을 작성해 변환부터 Main 왕복과 개발 Photon 두 연결까지 검증해줘. 조사나 계획에서 멈추지 말고 구현, 검증, 문서 갱신까지 진행해줘.

## 착수

1. `CLAUDE.md`, `PROJECT_DOCUMENTATION.md`, `Docs/QUANTUM_MIGRATION.md`, `Docs/NEXT_SESSION.md`를 읽어. 실제 수정 영역에 필요한 규칙과 기능 문서만 추가로 읽고, 원본 동작이나 측정 근거가 필요할 때만 Notes를 확인해. 피격 규칙은 제품9 피격/넉백 구현과 그 Notes를 기준으로 삼아.
2. Git 상태와 열린 Unity 씬의 미저장 여부를 확인하고 기존 작업을 보존해. 프로젝트 파일에서 Unity 6000.6.8f1과 Quantum 3.0.14 Stable 2241을 확인해.
3. 원본 `CannonShooter`, `CannonProjectile`과 `Cannon`·`CannonBall`·`PowerCannonBall`·`MapEditorCannon` 프리팹을 실제 스테이지 배치(Stage 6·8·9·10·11·15·17·18·20·21)와 대조해. 다음을 확인해.
   - 발사 간격, 첫 발사 시점, 방향·회전, 발사 위치 오프셋
   - 투사체 속도·중력 여부·수명, 일반탄과 강화탄의 차이
   - 충돌 마스크와 각 대상(지형, 플레이어, 상자, 다른 장치, 투사체끼리)에서의 소멸·관통·피격
   - 넉백 방향·크기와 무적 시간, 운반 중 대상에 맞았을 때의 처리
   - 이동 발판·전환 지형·OnOff 그룹과의 연결 여부, 서버 생성·풀링 방식
   원본에 없는 중대한 게임 규칙 결정만 질문해.

## 구현

- 원본 동작을 FP·틱·프레임 상태로 옮겨. 투사체는 결정론적 엔티티 생성·소멸로 다루고, 발사 타이머는 틱 카운터로 둬. 50Hz 원본 수치는 60Hz로 환산하고 환산 근거와 오차를 기록해.
- 투사체 이동과 충돌의 적용 순서를 이동 발판·플레이어 이동과의 관계 속에서 명시해. 빠른 투사체의 관통(터널링), 같은 틱의 다중 충돌, 생성 지점이 지형이나 플레이어와 겹칠 때, 리셋·복귀·도착 때 남아 있는 투사체를 각각 확인해. 동시 존재 투사체 수의 상한과 넘쳤을 때의 처리를 정해.
- 피격은 제품9 피격/넉백 경로를 재사용하고 새 규칙을 따로 만들지 마. 운반자·운반된 플레이어·상자·느슨한 상자에 맞았을 때의 결과를 확인해.
- 이동 대포나 OnOff 그룹 연결이 원본에 있으면 제품11·12 경로를 재사용하고, 지원할 구성과 거부할 구성을 분명히 해.
- Quantum 전용 작성 컴포넌트, 변환·해시·프레임 기반 표시와 별도 공식 시험 맵을 추가해. 최소한 일반탄·강화탄(원본에 차이가 있으면)과 지형 소멸·플레이어 피격을 맵이나 직접 검사로 재현해. 누락·중복·잘못된 참조·미지원 형상은 위치와 원인을 표시하며 거부해. 새 콘텐츠와 제품 합의 버전을 갱신하고 기존 공식 맵 해시 7종과 MapData 2.1 호환성을 확인해.
- 원본 21개 스테이지를 보존하고 Stage7의 직접 이식은 보류해. 공식 스테이지 등록, 최대 4인 확장과 Steam 출시 인증은 후속 범위로 둬.

## 검증과 완료

- 저장소 지정 dotnet 런타임·에디터 빌드와 Unity 컴파일을 확인해. 새 Play 세션에서 `QuantumProductChecks.RunOffline`을 다른 Main 검사보다 먼저 실행해.
- 실제로 공급한 입력을 기록하고 별도 러너에서 재생해 같은 확정 프레임의 체크섬, 발사 틱·투사체 생성/소멸·피격 프레임, 전원 완료 프레임을 비교해. 완료 프레임 절대값은 세션 시작 틱에 따라 달라지므로 프레임 번호 기준으로 비교해.
- 기존 Tilemap·공식 맵·경사·피격·스프링/바운스·제품11 이동 발판/트랩·제품12 스위치/문·제품13 컨베이어 회귀를 실행해.
- Main에서 새 맵 선택 → 플레이 → 전원 완료 → 복귀 → 재진입 → 메뉴 종료를 확인해. 개발 Photon 동일 PC 두 연결에서 대포·투사체·피격 상태와 확정 체크섬, 완료 프레임을 비교해. 각 종료 뒤 러너·연결·입력·남은 투사체 엔티티 정리를 확인하고 미실행 환경은 따로 적어.
- 관련 기능 문서의 현재 상태·검증·다음 작업을 갱신해. 구현 범위, 원본과 달라진 규칙과 이유, 검증 결과, 남은 제약을 한국어로 보고해. 완료 후 이 프롬프트 파일은 정책에 따라 지워.
