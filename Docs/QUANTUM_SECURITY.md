# Quantum·Steam 온라인 보안 설계

- 상태: Draft (인증 경계 일부 구현, 출시 공급자·실계정 검증 미완료)
- 기준: 2026-11-05 KST. 실제 전환 구현·검증 상태는 [Quantum 실행 기반](QUANTUM_MIGRATION.md)을 따른다.

## 현재 상태

- Steam 로비 모드에 따라 Mirror/FizzySteamworks 또는 Quantum으로 분기한다. Quantum 생성·참가는 출시 App ID와 로그인 상태를 먼저 확인한다. 세션은 별도 출시 Photon App ID와 `SteamPhotonTicket`을 요구하며 미설정·개발 앱 선택을 거부한다. Photon이 반환한 계정과 확정한 Steam 로비 참가자를 대조한다. 서버 구매 인증·차단은 출시 공급자 설정 후 확인한다.
- Steamworks.NET 2024.8.0의 `GetAuthTicketForWebApi`·응답 콜백·`CancelAuthTicket`을 사용한다. 공급자는 `version=2`, `identity=photon`, `verifyOwnership=true`가 필요하다. 사용자가 Steam 출시 앱 미발급을 확인해 실제 공급자 설정과 실계정 검증은 차단됐다.
- 개발 Quantum 앱은 생성했으며 에디터 전용 클라우드 시험에 사용한다. 출시 앱·Publisher 키·Steam 공급자는 미설정이다. 게임 온라인 경로는 Steam 티켓 실패 시 익명 접속으로 대체하지 않는다.
- 목표는 Steam 이용 권한이 없는 사용자의 공식 Photon 온라인 접속을 차단하는 것이다. 로컬 복제·변조 실행과 비공식 서버까지 완전히 차단한다고 보장하지 않는다.
- 구매 인증, 방 입장 권한, 데이터 검증, 치트 방지는 서로 별개다. Quantum 결정론·맵 해시·체크섬을 구매 인증이나 완전한 부정행위 방지 수단으로 취급하지 않는다.

## 핵심 흐름

1. 클라이언트가 Steam에서 해당 게임의 인증 티켓을 발급받는다.
2. Photon Steam 인증 공급자가 티켓과 대상 Steam App ID를 검증한다.
3. 공급자의 `verifyOwnership=true`로 게임 소유권 검사를 추가한다.
4. 인증으로 확인된 계정을 Photon 플레이어 식별에 사용한다. 클라이언트가 보낸 SteamID 문자열만 신뢰하지 않는다.
5. 인증에 성공한 연결만 방 생성·입장 및 Quantum 세션에 사용한다.
6. 초대·공개 범위·최대 인원·시작 여부 등 방 입장 정책은 인증과 별도로 검사한다.

## 출시용 구성

- Photon의 Steam 인증 공급자를 설정하고 익명 접속 허용을 해제한다. UI뿐 아니라 Photon 연결 단계에서 강제한다.
- 인증 실패·인증 서비스 장애 시 무인증 온라인 접속으로 대체하지 않는다. 실패 사유를 구분해 안내하고 재시도를 제공한다.
- Steam Publisher Web API 키는 Photon 대시보드 또는 신뢰하는 서버에만 보관한다. 클라이언트·Git·로그·문서에 기록하지 않는다.
- Photon App ID와 Steam App ID는 비밀 키가 아니다. 이를 숨기는 것으로 접속을 보호하지 않는다.
- SDK와 Steamworks.NET 버전에 맞는 티켓 API·공급자 `version`·`identity` 조합을 확인한다. 비동기 발급 완료 후 전송하고 문서에 따라 티켓을 정리한다.
- 개발용과 출시용 Photon 앱을 분리한다. 테스트 계정·App ID 480·에디터 인증 우회가 출시 앱의 보호 증거가 될 수 없다.
- 개발용 오프라인 테스트는 허용하되 출시용 온라인 인증 우회·게스트 폴백을 넣지 않는다.
- 계정 중복 접속과 티켓 재사용 처리의 실제 동작을 확인한다. 1회 로그인 검증을 지속적인 이용 권한 검사로 간주하지 않는다.
- Steam 가족 공유 등 지원할 정당한 이용 권한의 허용 정책과 공급자 판정을 실제 계정으로 확인한다. 직접 구매 여부만으로 불법 복제를 단정하지 않는다.

## 방·맵·세션 보호

- 초대 링크나 방 이름은 인증 수단이 아니다. 비공개 방은 초대 대상·예약 등 서비스가 강제할 수 있는 입장 정책을 별도 검증한다.
- 빌드·시뮬레이션·콘텐츠 버전이 다른 사용자를 분리한다. AppVersion 구분은 변조 방지의 증거가 아니다.
- 현재 맵 최대 512 KiB 정책을 출발점으로 삼고 Photon의 실제 메시지 제한에 맞게 청크 크기를 정한다.
- 길이·청크 수·객체 수·팔레트 ID·좌표 범위·참조·맵 스키마를 검증하고 전송량·동시 전송·제한 시간을 제한한다.
- 맵 해시, 변환 버전, 팔레트 버전과 전원 준비를 확인한 뒤 시작한다. 해시는 콘텐츠 일치 확인용이며 제작자 신원 증명이 아니다.
- 자동 수신 맵은 세션 캐시에 보관하고 영구 저장은 사용자 승인 흐름을 유지한다. 파일명·경로는 수신자가 안전하게 결정한다.
- 판정에 영향을 주는 값은 Quantum 프레임 상태에서 관리한다. 클라이언트 연출이나 외부 Unity 상태를 판정 근거로 사용하지 않는다.
- 최초 전환에서는 진행 중 신규 입장·재입장 제한을 유지한다. 방장 이탈 정책은 실제 기존 동작을 확인해 이식하고 별도 정책 변경은 분리한다.

## 검증

- Steam Quantum 로비 생성 전 출시 설정 누락을 차단했다. 에디터 모의 로비의 확정 참가자와 실제 개발 Photon 두 연결의 사용자 ID 대조 및 입장 잠금을 확인했다. 출시 Steam 티켓·실계정 소유권·공급자 익명 차단은 미실행이다.

- 제품5/ff-product-5 새 개발 Photon 장치 맵 두 연결은 asia·같은 PC·주입 없음, 확정19개/완료2687·RTT114/115ms 일치와 종료 정리를 통과했다. [장치 기록](Notes/2026-11-08-quantum-devices.md)은 출시 Steam 공급자/소유권/익명 차단 검증이 아니다. 출시 앱 미발급·보안 Draft를 유지한다.

- 2026-11-08 제품4/ff-product-4 새 개발 Photon 복귀19개·완료2640/RTT108·116ms, 로프/이동15개·상호작용11개 체크섬 일치·출시 설정 실패/익명 폴백 없음 유지. asia·같은 PC·주입 없음이며 [새 기록](Notes/2026-11-08-quantum-respawn.md)은 출시 Steam 인증 증거가 아니다. Draft를 유지한다.
- 2026-11-07 상호작용 제품3·AppVersion ff-product-3에서 새 개발 Photon 두 연결을 실행했다. asia·같은 PC·주입 없음, 상호작용 확정 체크섬11개/완료1586 일치, 종료 정리와 출시 설정 실패/익명 폴백 없음은 유지했다. [새 측정](Notes/2026-11-07-quantum-interactions.md)은 출시 Steam 공급자·소유권·익명 차단 검증이 아니다. Draft를 유지한다.
- 2026-11-06 Main 제품 온라인 버튼의 출시 설정 미완료 실패·재시도 UI와 익명 폴백 없음, 제품 개발 앱의 대기 취소·콘텐츠 불일치 거부·종료 자원 정리를 새 실행으로 확인했다. 개발 접속 메서드는 `UNITY_EDITOR`에만 있다. [실행 기록](Notes/2026-11-06-quantum-product-integration.md)은 출시 서버 인증·소유권·익명 차단이나 플레이어 빌드 실조작 검증이 아니다.
- SDK 임포트·오프라인 2인·입력 재생을 실행했으며 범위는 실행 기반 문서를 따른다. 구매 인증·차단 효과·Steam 실계정 테스트는 미실행이다.
- 허용: 정당한 이용 권한이 있는 서로 다른 계정 2~4개의 인증·친구 초대·입장·맵 전송·플레이.
- 거부: 티켓 누락·잘못된 티켓·다른 App ID 티켓·미소유 계정·익명 연결·다른 인증 경로로 출시 앱 직접 접속.
- 인증 UI를 거치지 않는 테스트 클라이언트도 Photon 서버에서 거부되는지 확인한다.
- 수명: 만료·취소·재사용 티켓, 중복 계정 접속, 로그아웃, 환불·라이선스 회수 이후 재접속을 확인한다.
- 장애: Steam/Photon 인증 실패와 시간 초과에서 무인증 폴백이 없고 정상 복구 시 재시도할 수 있는지 확인한다.
- 데이터: 손상·과대 맵, 잘못된 청크·팔레트·좌표·버전, 전송 중 선택 변경과 이탈을 검사한다.
- 출시 빌드·저장소·로그에 비밀 키·티켓과 개발 우회가 포함되지 않았는지 확인한다.
- 가족 공유 등 권한별 실제 결과를 기록한다. 계정·SDK·설정 부족으로 못 한 검사는 통과로 표시하지 않는다.

## 남은 작업

- Steam 출시 앱 발급 후 Photon 출시 앱·Steam 공급자를 설정하고 구현한 티켓 경계를 실제 서버와 연결해 검증한다.
- 직접 구매 외 라이선스·환불·중복 접속 정책과 공급자 동작을 실계정으로 확정한다.
- 기본 인증만으로 부족한 차단·세션 제어가 확인될 때 별도 백엔드/웹훅 도입을 검토한다. 초기에는 자체 인증 서버를 필수로 두지 않는다.
- Steam 실행 연동은 보조 수단으로 사용한다. Steam DRM 래퍼를 Unity 실행 파일에 무조건 적용하지 않고 빌드 호환성을 확인한다.

## 다음 작업

- Steam 앱 발급 후 별도 출시 Photon 앱에서 공급자와 익명 거부를 설정하고 티켓 누락·변조·미소유·다른 앱·인증 생략 직접 연결 거부를 실제 서버에서 확인한다.
